##update 2026-05-21 docker-compose stuff


docker compose build — builds the image from the Dockerfile, tags it as glftpd. Doesn't start anything. 
docker compose up -d — builds the image if it doesn't exist yet, then starts the container. Doesn't rebuild if the image already exists, even if you changed the Dockerfile. 
docker compose up -d --build — forces a rebuild before starting. This is what you want after editing the Dockerfile.
docker compose build --no-cache — full rebuild from scratch, ignoring Docker's layer cache. Useful when you've changed something that the cache doesn't detect (like a remote dependency you want to refetch).
